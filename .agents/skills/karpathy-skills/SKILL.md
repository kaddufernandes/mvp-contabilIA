# Andrej Karpathy Skills & Workflows

Este skill fornece padrões de desenvolvimento inspirados em Andrej Karpathy para guiar a criação de código, refatoração e resolução de bugs no projeto.

## Princípios Chave:
1. **Simplicidade Absoluta (Keep it Simple):** Evitar abstrações prematuras. Escrever código direto, legível e de fácil manutenção.
2. **Investigação Antes de Edição:** Ler os arquivos relevantes e tracebacks completos antes de fazer alterações.
3. **Refatoração Segura por Etapas:** Mudar um módulo de cada vez, validando a execução do servidor a cada passo.
4. **Sem Mapeamentos ou Fallbacks Ocultos:** Tratar exceções na causa raiz.
